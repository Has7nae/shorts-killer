# Shorts Killer

Расширение для Chrome / Opera / Edge, которое помогает осознанно ограничивать просмотр YouTube Shorts.

Не блокирует весь YouTube — мешает только бесконечному скроллу Shorts.

## Возможности

- **Мягкий режим** — оверлей, таймер и случайный вопрос перед просмотром
- **Жёсткий режим** — Shorts сразу блокируются, возврат на обычный YouTube
- **Дневной лимит** — сколько Shorts можно посмотреть за день
- **Строгий лимит** — после достижения лимита его нельзя увеличить до следующего дня
- **Скрытие Shorts** — убирает карточки и полки Shorts с главной, поиска и подписок
- **Локальная статистика** — срабатывания, просмотры, оценка сэкономленного времени
- **Telegram-отчёт** — отправка сводки по кнопке (по желанию)

## Установка

1. Скачай или клонируй этот репозиторий
2. Открой страницу расширений:
   - Chrome: `chrome://extensions`
   - Opera: `opera://extensions`
   - Edge: `edge://extensions`
3. Включи **Режим разработчика**
4. Нажми **Загрузить распакованное расширение**
5. Выбери папку с файлами проекта

После установки иконка Shorts Killer появится в панели расширений.

## Как пользоваться

1. Открой popup расширения
2. Выбери режим:
   - **Мягкий** — сначала вопрос и таймер, потом можно продолжить
   - **Жёсткий** — Shorts блокируются сразу
3. При необходимости настрой:
   - длительность таймера
   - дневной лимит
   - строгий лимит
   - скрытие Shorts на страницах YouTube
4. Смотри статистику за сегодня и за неделю

### Telegram (опционально)

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. Напиши боту `/start`
3. Узнай свой Chat ID через [@userinfobot](https://t.me/userinfobot)
4. Вставь токен и Chat ID в настройках расширения
5. Нажми **Отправить отчёт сейчас**

Хостинг бота не нужен: расширение само отправляет сообщение через Telegram Bot API.

## Приватность

- Обычная статистика хранится только локально в `chrome.storage.local`
- История просмотров на сторонние серверы не отправляется
- Telegram используется **только** при явной отправке отчёта пользователем
- Токен бота хранится локально в профиле браузера
